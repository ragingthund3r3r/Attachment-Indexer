# Attachment Indexer

A plugin for indexing and managing attachments in your Obsidian vault.

## Installation

- Clone or download this repository into your vault's `.obsidian/plugins` directory
- Run `npm i` to install dependencies
- Run `npm run build` to compile
- Enable the plugin in Obsidian's plugin settings

## Development

- Run `npm run dev` to start compilation in watch mode
- Edit files in the `src` directory
- Changes will automatically compile to `main.js`
- Reload Obsidian to see updates

## Building

- Run `npm run build` to create a production build
- Artifacts (`main.js`, `manifest.json`) will be generated at the root
